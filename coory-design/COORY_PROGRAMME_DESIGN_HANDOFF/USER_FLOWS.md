# Parcours utilisateurs

## UF-01 Créer un programme depuis zéro
01 → « Créer un programme » → 02 étape 1 (sportif, titre) → 2 (discipline, objectif, façon de viser) → 3 (dates, semaines, séances/sem., phases, organisation) → 4 « Partir de zéro » → « Créer le brouillon » → 03 éditeur (semaines vides) → remplir les séances (04/05/06) → « Publier » (08) → toast → le sportif voit le programme (07, 2c).

## UF-02 Partir d'un modèle Coory
01 onglet Modèles → filtre Coory → « Utiliser » sur « Prépa Hyrox · 12 semaines » → 02 (étape 4 « Partir d'un modèle » choisie) → choisir sportif + date de début → brouillon = copie datée → 03.
Variante : ouvrir le modèle (03 lecture seule, 1g) → « Dupliquer dans Mes modèles » → modèle modifiable.

## UF-03 Enregistrer un programme comme modèle
03 → ··· → « Enregistrer comme modèle » → nom [P : modale non dessinée] → apparaît dans Modèles / Mes modèles, sans sportif ni dates.

## UF-04 Ajouter une séance depuis un modèle
03 → « Depuis un modèle » → choix d'une séance modèle (Mes modèles / Coory) [P : sélecteur non dessiné] → copie insérée en fin de semaine.

## UF-05 Fixer les jours d'une semaine
03 → semaine → « Jours fixes » → modale de proposition (FIX-01) → ajuster → portée → « Fixer les jours » → bandeau + pavés jour (FIX-02) → clic sur un pavé → panneau jour (choix, heure, portée, autorisation de déplacement) → Valider → « Modifications non publiées » → Publier.

## UF-06 Cibler une étape Running en zone de FC
04 → étape → panneau → « Zone de FC » → Z4 → plage proposée depuis la FC max → Valider. Sans FC max : champs vides à remplir.

## UF-07 Musculation en % du max
05 → exercice → Charge « % du max » → saisir 70 % → kg calculés affichés.

## UF-08 Simulation Hyrox
06 → « Simulation de course » → feuille 6c → « Officielles » (ou Mes charges) → corriger un temps cible → « Insérer la simulation ».

## UF-09 Générer et envoyer les PDF
03 → « PDF » → génère PDF 1 (Agenda, 1 + N pages) et PDF 2 (Fiches et repères) → envoi au sportif en une fois [P : écran d'envoi non dessiné].

## UF-10 Sportif consulte sa séance
Agenda (2c) → carte séance → dépliage → blocs écrits → (feedback [P]).
