# Transitions d'état

## Programme
`brouillon` →(Publier)→ `publié vN` →(modification)→ `publié vN + brouillon` →(Publier)→ `publié vN+1`
`publié` + date de début future = **À venir** ; en cours de période = **En cours** ; après la fin = **Terminé** ; →(Archiver)→ `archivé` [D statuts de la liste 01].

## Modèle
`Mes modèles` : modifiable · `Coory` : lecture seule →(Dupliquer dans Mes modèles)→ copie `Mes modèles`.

## Semaine
`dans l'ordre` ⇄ `jours fixes` (03b). Semaine passée : figée.

## Séance (côté sportif)
Dessiné : `à faire` → `prochaine` (la première non faite) → `faite` (avec RPE / ressenti).
Non dessiné [P] : `manquée` (semaine terminée sans réalisation), `reportée` (déplacée hors de sa semaine), `annulée` (par le coach). À valider avant développement.

## Séance à jour fixe
`sans jour` ⇄ `jour fixé` ; `jour fixé` + autorisation → le sportif peut `déplacer` (même semaine) → notification coach.
Séance coach : `verrouillée` (date du rendez-vous).

## Assistant 02
étape 1 → 2 → 3 → 4 → `brouillon créé`. Retour possible à toute étape déjà vue. Étape 1 sautée si lancé depuis la fiche d'un sportif (sportif pré-choisi).

## Éditeur de séance
`enregistré` (auto, libellé « Enregistré ») [D] ; erreurs de sauvegarde [P].
