## Limites honnêtes
- Mesures : **EXACT** car lues dans le code (styles inline) ; pas de relevé X/Y pixel par pixel élément par élément — le code source et les captures servent de référence géométrique.
- Captures : 1× pour les écrans, 2× pour les pages PDF ; les cadres d'appareil (rayon, ombre) font partie de la planche, pas de l'app.
- États hover / focus / loading / erreur : non dessinés, proposés.
- Les PDF sont des **prototypes HTML** ; la compatibilité lecteurs est à tester.
