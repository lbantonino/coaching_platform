# Règles métier

| ID | Règle | Source |
|---|---|---|
| BR-01 | Un programme appartient à un coach et à un seul sportif. | [D] |
| BR-02 | Les séances d'une semaine sont numérotées 1…M ; en « dans l'ordre », le sportif les fait dans l'ordre, au jour de son choix. | [D] |
| BR-03 | En « jours fixes », chaque séance a un jour (lun–dim) et une heure facultative ; la numérotation suit l'ordre des jours. | [D] 03b |
| BR-04 | Deux séances le même jour : autorisé, avec avertissement. | [D] 03b |
| BR-05 | Jour indisponible (onglet Disponibilités du sportif) : non proposé, sélectionnable avec avertissement [P] ; affiché barré. | [D]/[P] |
| BR-06 | Séance avec le coach : date + heure du rendez-vous ; jour verrouillé ; pour la déplacer, on change le rendez-vous. | [D] |
| BR-07 | Portée d'un changement de jour : cette semaine / phase / programme. Les semaines passées ne changent jamais. | [D] |
| BR-08 | Si autorisé, le sportif peut déplacer une séance à jour fixe dans la même semaine ; le coach est notifié. | [D] |
| BR-09 | Toute modification d'un programme publié crée un brouillon (« Modifications non publiées ») ; publier crée vN+1. | [D] |
| BR-10 | Utiliser un modèle crée une copie ; la copie n'affecte jamais le modèle. Un modèle Coory n'est pas modifiable (lecture seule, « Dupliquer dans Mes modèles »). | [D] |
| BR-11 | Un modèle n'a ni sportif ni dates : « Semaine 1 à N ». | [D] |
| BR-12 | Façon de viser par défaut fixée au programme (Running : allure / FC ; Musculation : kg / %), pré-choisie selon les repères ; modifiable séance par séance et étape par étape. | [D] |
| BR-13 | Allure calculée depuis la VMA ; zones FC depuis la FC max (Z4 = 84–91 % → 161–175 bpm pour 192) [P pour les bornes exactes des zones] ; sans repère : saisie libre. | [D]/[P] |
| BR-14 | En % du max : kg affichés = % × max du sportif pour l'exercice (arrondi PROPOSED : au 0,5 kg). | [D]/[P] |
| BR-15 | Hyrox : charges officielles = celles de la catégorie du sportif (ex. Open Femme : sled push 102 kg, sled pull 78 kg, farmers 2 × 16 kg, sandbag 10 kg, wall balls 4 kg). Une simulation applique toutes les charges officielles en un choix, corrigeables ligne par ligne. | [D] |
| BR-16 | Unités : course min/km ; ergomètres min/500 m (jamais mélangés). | [D] |
| BR-17 | Phases facultatives ; une semaine appartient au plus à une phase ; plages contiguës [P]. | [D]/[P] |
| BR-18 | Aucune représentation graphique d'une séance (barres, courbes). | Décision client |
| BR-19 | Les PDF sont un instantané à la date de génération ; régénérés à chaque publication [P]. | [P] |
| BR-20 | Pas d'envoi automatique hebdomadaire des PDF (fonction reportée). | Décision client |
