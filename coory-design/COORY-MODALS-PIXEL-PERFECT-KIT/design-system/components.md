# Composants communs

- **ModalShell** : overlay + conteneur + en-tête optionnel (retour, titre, sous-titre, ✕) — variantes `center`, `anchored`, `sheet`.
- **ActionMenu** : liste d’`ActionItem` (tuile icône, libellé, description, état sélectionné, chevron, texte droit, destructif), `MenuSection`, `MenuDivider`, `MenuProfile`, `MenuSegmented`, `MenuCheck`.
- **FormModal** : corps grille 12/2 colonnes + pied fixe (Supprimer / Annuler / Principal).
- **Field** : TextInput, Select, DateInput, TimeInput, Textarea, Segmented, ChoiceChips, CheckCard, Hint, FileDrop, CategoryList, AddRow.
- **ConfirmDialog** : tuile icône 52 px, titre, texte avec nom en gras, Annuler + bouton danger.
- **WidePanel** : aperçu de document, paramètres (navigation latérale).

Détails : `shared-components/`.
