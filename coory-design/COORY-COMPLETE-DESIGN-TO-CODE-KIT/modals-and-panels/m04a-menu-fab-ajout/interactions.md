# Menu du bouton + (Comptabilité mobile) — interactions

| Aspect | Règle |
|---|---|
| Ouverture | Tap FAB ; overlay ou × ferme |
| Overlay | voir desktop/mobile-spec |
| Focus | piégé dans le composant, retour au déclencheur à la fermeture |
| Scroll | page bloquée derrière ; scroll interne seulement |
| Validation / confirmation | Chaque item ouvre la modale existante correspondante (kit Modals). |
| Annulation | Échap, clic extérieur, bouton Fermer/Annuler |
