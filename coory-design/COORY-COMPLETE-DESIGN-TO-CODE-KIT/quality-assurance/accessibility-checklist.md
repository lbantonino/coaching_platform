# Checklist accessibilité

> Validation globale H, 05/11/2026 (D-135) : mesures automatiques sur les 16 écrans des 13 pages (script Playwright), puis vérification à l'œil des cas douteux.

- [x] Tout est utilisable au clavier (Tab, Maj+Tab, Entrée, Espace, Échap, flèches dans les menus). 45 Tab par écran sans piège ; Échap ferme les 6 fenêtres testées (boîte Assistant, Nouveau message, Importer, options d'une liste, Nouvelle dépense, menu du compte) sur ordinateur ET téléphone, et le focus revient sur le bouton d'origine ; flèches dans les menus (overlay.tsx, dropdown.tsx).
- [x] Focus visible partout. Les vraies cases cachées (pastilles, segments, interrupteurs) montrent l'anneau violet sur leur dessin ; les champs l'affichent sur leur cadre ; les lignes « étirées » (Notifications, Documents) sur toute la ligne ; « ··· » des listes apparaît au focus.
- [x] Contrastes ≥ 4.5:1 pour le texte (décision d'Antonino, D-136) : variantes « texte » des couleurs dans le design system (`--run-text`, `--strength-text`, `--female-text`, `--male-text`) pour les pastilles de catégorie et les ♀ / ♂ des avatars ; compteurs et « Valider N actions » sur le violet d'action (`--accent`, 5,1:1) ; nombre de l'onglet « Non lues » en `muted`. Nouvelle mesure (sombre et clair, 1280 et 390) : 0 texte sous le seuil.
- [x] aria-label sur tous les boutons icône. 0 contrôle sans nom accessible, à toutes les largeurs.
- [x] Rôles : switch, checkbox, menu, dialog (fenêtres natives `<dialog>`, aria-modal). Les « onglets » qui changent l'adresse (Tâches, Messages, Comptabilité) sont des liens avec `aria-current="page"` ; ceux des Notifications des boutons `aria-pressed` : pas de `tablist` volontairement (chaque vue a son adresse).
- [x] Zones tactiles ≥ 44 px. Mesurées au doigt (points réellement atteignables, pseudo-éléments compris), pages entières, à 390 px. Corrigé sans changement visuel : ajout rapide des Tâches (22 -> 50 px), « Voir la fiche » d'un fil (18 -> 44), « Envoyer » de l'Assistant (36 -> 44), bascule anneau / barre (30 -> 44 de haut) ; puis (D-136) toutes les pastilles, segments et puces (onglets, filtres, rubriques, muscles, lieux, jours, inscrits, Virement / Espèces, Statut, Thème) par l'utilitaire `tap-44` (calque invisible, écrans tactiles seulement ; captures avant / après identiques au pixel). Exceptions assumées : icônes de la barre du haut (40 px, cadre protégé), barres du graphique et lignes de légende de la Comptabilité (40 px, collées les unes aux autres), filtres de paiement de la Comptabilité (42 px).
- [x] prefers-reduced-motion respecté (durée la plus longue mesurée en mouvement réduit : 0,01 ms).
