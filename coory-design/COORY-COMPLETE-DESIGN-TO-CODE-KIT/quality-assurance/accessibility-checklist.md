# Checklist accessibilité

- [ ] Tout est utilisable au clavier (Tab, Maj+Tab, Entrée, Espace, Échap, flèches dans les menus).
- [ ] Focus visible partout.
- [ ] Contrastes ≥ 4.5:1 pour le texte (cf. design-system/accessibility.md).
- [ ] aria-label sur tous les boutons icône.
- [ ] Rôles : tablist, switch, checkbox, menu, dialog.
- [ ] Zones tactiles ≥ 44 px.
- [ ] prefers-reduced-motion respecté.
