Ces fonctionnalités n'existent pas encore dans l'app. Ce ne sont pas des changements de design : Claude Code doit les développer en plus. Elles demandent un modèle de données (listes : nom, couleur, ordre ; chaque tâche liée à une liste), la création, le renommage et la suppression d'une liste, et le filtrage des vues automatiques.

Listes de tâches, comme Rappels et Google Tasks. Le coach range ses tâches dans des listes (Programmes, Facturation, Fiches sportifs, Bibliothèque…) et peut en créer d'autres avec « Nouvelle liste ». Quatre vues automatiques regroupent toutes les listes : Aujourd'hui, À venir, Toutes, Terminées. Dans ces vues, chaque tâche affiche le nom de sa liste.

Création rapide, comme Rappels. Le coach n'est pas obligé d'appuyer sur « + ». Toucher la zone vide sous la liste crée directement une tâche dans la liste ouverte :

  • une ligne vide apparaît à la fin, curseur prêt ; sur mobile, le clavier s'ouvre ;
  • Entrée enregistre et ouvre une nouvelle ligne ;
  • quitter le champ enregistre ; un champ vide est annulé ;
  • le « + » (mobile) et « Nouvelle tâche » (desktop) font la même chose.
Essaie sur les maquettes : choisis une liste, puis touche la zone vide sous les tâches.
