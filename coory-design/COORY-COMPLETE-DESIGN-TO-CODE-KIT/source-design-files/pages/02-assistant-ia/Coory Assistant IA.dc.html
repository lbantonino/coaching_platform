NOTEÀ reporter dans le brief Claude CodeNOUVELLE FONCTIONNALITÉ
  • Bouton « Assistant IA » de la barre du haut : ouvre une boîte de dialogue par-dessus n’importe quelle page. Desktop : panneau centré sur l’écran (marges gauche et droite égales), juste sous la barre du haut ; une petite pointe le relie au bouton, qui reste allumé. Mobile : panneau clair qui descend juste sous le bouton (petite pointe vers le bouton, qui reste allumé), détaché des bords. Les raccourcis sont dans le « + ». La page derrière s’assombrit ; toucher le fond ou Échap ferme.
  • « Assistant IA » dans le menu de gauche : ouvre la page complète, avec l’historique des conversations.
  • « Plein écran » dans la boîte fait passer la conversation en cours sur la page complète.
  • L’assistant ne fait jamais rien seul : il propose des actions à cocher, le coach valide.
