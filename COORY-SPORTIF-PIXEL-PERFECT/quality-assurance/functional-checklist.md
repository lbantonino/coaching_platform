# Checklist fonctionnelle
- [ ] Tous les boutons déclenchent l’action existante (ou nouvelle, documentée).
- [ ] Menus déroulants : ouverture, sélection, fermeture (clic extérieur, Échap), `aria-expanded`.
- [ ] Filtres et recherche (1a) filtrent les vraies données ; compteurs exacts.
- [ ] Tri des colonnes (1a).
- [ ] Sélection multiple + actions groupées (1a).
- [ ] Navigation : liste → fiche → onglets → détail de séance → retour.
- [ ] Formulaires : enregistrement, validations, messages d’erreur existants.
- [ ] Données réelles (aucune donnée de démo codée en dur).
- [ ] Permissions inchangées (coach de l’organisation uniquement).
