# Modales et surcouches

Aucune modale n’est dessinée dans la planche. Seules surcouches : **menus déroulants** (voir ../design-system/components.md).
- Les actions destructives (Supprimer un objectif, Retirer l’accord, Retirer la photo, Archiver) n’ont pas de confirmation dessinée → **conserver la confirmation existante de l’app** si elle existe ; sinon à décider (À vérifier par Claude Code).
- Le sélecteur de fichier (Changer la photo, Importer un document) utilise le mécanisme existant de l’app.
